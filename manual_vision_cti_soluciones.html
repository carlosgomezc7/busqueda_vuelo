Manual Maestro: VISION

Sistema de Inteligencia, Memoria Sintética y Modelo de Trabajo B2B para Intranets con Deep Search

1. Resumen Ejecutivo & Posicionamiento B2B

CTI Soluciones evoluciona hacia el desarrollo de Intranets Empresariales y Portales Corporativos a la Medida, impulsados por Inteligencia Artificial y motores de Búsqueda Profunda (Deep Search / RAG).

Para escalar este modelo operativo, se establece VISION: un servidor de Memoria Sintética (basado en Protocolo MCP - Model Context Protocol) diseñado para retener todo el conocimiento comercial, técnico, arquitectónico y las lecciones aprendidas de cada proyecto B2B.

2. Fases y Subtareas del Plan Maestro

Fase 1: Estructura del Proyecto y Entorno de VISION

  • Subtarea 1.1: Crear el directorio local ~/Documents/vision/ y la estructura de carpetas (src/memory/, src/tools/, src/seed_data/).
  • Subtarea 1.2: Inicializar entorno virtual Python (venv) e instalar dependencias clave: mcp, fastmcp, chromadb, sentence-transformers, python-dotenv.
  • Subtarea 1.3: Crear archivos de configuración base (.gitignore, requirements.txt, .env.example, README.md).
  • Subtarea 1.4: Inicializar el repositorio Git local para el control de versiones.

Fase 2: Elaboración de la Memoria Semilla (Seed Data)

  • Subtarea 2.1: Redactar 01_modelo_negocio.md con la propuesta de valor comercial B2B de CTI Soluciones.
  • Subtarea 2.2: Redactar 02_intake_intranet.md definiendo el cuestionario de diagnóstico corporativo (RBAC, SSO, seguridad, módulos).
  • Subtarea 2.3: Redactar 03_deep_search_rag.md especificando la arquitectura de búsqueda inteligente sobre documentos internos.
  • Subtarea 2.4: Redactar 04_stack_empresarial.md con los patrones de desarrollo en Next.js (App Router), Tailwind CSS y Supabase (PostgreSQL + pgvector).

Fase 3: Desarrollo del Servidor FastMCP "VISION"

  • Subtarea 3.1: Implementar el módulo de memoria vectorial en src/memory/vector_store.py (ChromaDB).
  • Subtarea 3.2: Desarrollar el script src/memory/seeder.py para indexar automáticamente los documentos semilla.
  • Subtarea 3.3: Crear herramientas MCP en src/tools/ para generación de PRDs, consulta de blueprints y registro de retrospectivas.
  • Subtarea 3.4: Configurar el punto de entrada principal en src/main.py exponiendo el servidor FastMCP estándar.

Fase 4: Sembrado, Verificación y Respaldo en GitHub

  • Subtarea 4.1: Ejecutar el sembrado de memoria y realizar pruebas de consulta sintética en VISION.
  • Subtarea 4.2: Crear el repositorio remoto vision en GitHub y sincronizar el código fuente.
  • Subtarea 4.3: Configurar flujos de respaldo automatizado para proteger la base de conocimiento ante fallas de hardware.
  • Subtarea 4.4: Diseñar el Cuestionario Interactivo y la Landing Page comercial para el dominio ctisoluciones.com.
